# DoraPlay

Plataforma brasileira de streaming e loja de novelas verticais. *Sua próxima história começa aqui.*

**Status:** Etapa 1 (interface navegável de prévia) concluída; Etapa 2 em andamento por subetapas. As páginas atuais são prévias sem backend. O título "A Luna Traída que se Tornou a Rainha dos Lobos" e os preços são rascunho/provisórios, pendentes de confirmação de direitos com o fornecedor.

## Fonte oficial
- **GitHub** (`italonegocios17-beep/doraplay`) é a fonte oficial do código e da documentação.
- **Lovable** continua conectado ao repositório para tarefas que dependem do Lovable Cloud (autenticação, banco, funções de servidor).
